# DevPulse - Engineer's All-in-One Assistant & Productivity Hub

A cross-platform app (React Native) + backend (Node.js/Express) + cloud deployment (AWS EC2) built from 0 to production.

## Project Structure
- `backend/` - Node.js + Express REST API server, PostgreSQL + Prisma DB, integrations (Slack, LINE, LinkedIn, Weather, AI Reply Engine).
- `mobile/` - React Native (Expo) mobile client app for iOS & Android.
- `docker-compose.yml` - Local multi-container orchestration.
- `aws/` - Deployment scripts, Nginx configurations, and systemd units for AWS EC2.
